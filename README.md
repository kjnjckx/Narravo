# Narravo · 叙声

**从第一个灵感，到能听见的故事。**

本地优先的桌面小说创作、情境朗读与有声角色扮演工作台。目标覆盖从零创作、导入阅读、AI 续写，以及自定义角色单聊/群聊和聊天实时 TTS，需求基线见 [PRD.md](PRD.md)。当前目录即项目根目录。

## 当前进度

2026-10-17：P0 开发版，已实现本地写作闭环、多服务模型设置、真实协议适配与基础语音管线，并构建本机 macOS Apple Silicon 应用包。**尚未完成整个 PRD，也不是正式发行版。**

目前可用：

- 作品库双入口：新建原创作品、TXT / EPUB / 文本型 PDF 预览后导入；TXT 支持 UTF-8/BOM、UTF-16、GB18030 手动选择，自动检测结果需检查。
- 无模型写作：创建默认分支、第一章及稳定空锚点；Tiptap 按章编辑，停止输入 500 ms 后保存，正文按非空白 Unicode code point 计数。
- 桌面创作工作台三栏独立滚动：长正文在中间滚动，章节目录与写作/朗读面板各自滚动；章标题、正文工具栏和底部字数保持可见。
- 章节增删、改名、重排和手动状态；分支创建/切换，正文与规划独立演进。
- 手动简报、人物、世界观和章节大纲；人工锁定、作者秘密与按章节披露标记。
- 真实文本服务配置和流式候选：DeepSeek、OpenAI Chat/Responses、GLM、Claude、Gemini、通义千问、Kimi、硅基流动、OpenRouter、Ollama 及自定义兼容服务预设；模型 ID 可手填，实际账号权限需测试。支持正文/所选规划与用户意图、停止、用量、未知完成状态、上下文预算检查。
- MiniMax 中国/国际、OpenAI 和 ElevenLabs TTS：固定旁白音色、短句测试、已保存章正文分段合成、WAV/MP3 校验、缓存复用、播放/暂停/上一段/下一段/倍速，正文修改后停止旧音频。
- 独立设置页面：左侧导航进入，支持从创作/聊天返回并保留原编辑状态；LLM/TTS 分栏配置。系统凭据库存取/移除密钥；明确启用外部服务；短样本测试（可能计费），默认不自动请求；密钥绑定确切服务地址，修改地址不会静默转发旧密钥。
- 仍保留确定性的本地**演示候选**：流式进度、停止、候选编辑/片段选择、显式接纳、重复保护、正文与规划依赖冲突；任务可从任务中心找回。
- 三种上下文策略预览，显式选择规划与改写范围；空前文合法，未来计划不会作为历史事实；读者模式保守地在披露章节结束之后开放设定。
- 最近 30 个版本的历史查看与恢复；恢复产生新版本，保留原来的历史。
- TXT / Markdown 正文导出，排除作者规划和未接纳候选。
- EPUB 2/3 按 spine 顺序提取纯文本和目录标题；PDF 逐页提取、密码输入、遗漏页确认与可取消处理。扫描件明确提示先 OCR。
- 完整书库 `.narravo` 备份：历史、分支、规划、候选与接纳记录、原文件，可选音频；校验后恢复到独立书库并切换，可切回恢复前书库。模型配置、系统密钥与网络授权不随备份恢复。
- Rust ↔ Python 的版本化 JSON-RPC 2.0 stdio 桥接、请求超时、流式任务序号、退出前保存与引擎清理；Python 独占 SQLite 业务写入。

尚未完成：真实账号的提供商验收、人设遵从与听感评测、小说朗读的角色/情绪分析与多声音绑定、AI 结构化规划候选、FTS/中文检索、书签/阅读进度、写作/整章朗读的金额预算账本、正式签名公证及 Windows。**本轮真实协议适配已由 HTTP 替身测试，没有使用真实密钥、付费请求或账号验证；预设可配置不等于该账号的全部模型能力已经通过实测。** 费用未知时明确显示未知；写作/整章朗读仍以单次输出 token、合成字符数与并发限制约束请求；角色聊天已增加轮次累计请求/token/字符与可选金额预留。金额依据用户填入的本轮统一保守单价、币种、来源与日期估算，不是厂商账单。完整备份已基于一致性快照和资产校验落地；当前备份仅接受相同 schema 0004，尚不支持直接恢复 0003 备份、书库合并或加密备份。旧 0003 书库打开时先建立一致性升级备份并事务迁移。

## 角色扮演、群聊与分句语音

2026-10-17：新增左侧「角色」入口，独立于作品库。**实现已通过确定性与本机原生替身验证，真实模型、人设质量、真实语音听感与延迟目标尚未验收。**

1. 点击「新建角色 / 用户身份」，填写名称、公开简介、身份、背景、性格、动机/限制、关系、表达方式、开场白、示例、私有知识与声音偏好。可选本地 PNG 头像（128 KiB、512 像素以内）。保存、复制、归档均不调用模型；同名对象使用不同编号。
2. 点击「新建单聊 / 群聊」，选 1–8 位角色、可选用户身份和共享场景。无模型时可以保存人设、创建会话、保存本地用户消息、浏览和导出；不会生成假回复。
3. 选择设置中已有 LLM，发送消息或按 Ctrl/⌘ + Enter。复用现有真实流式 adapter 与系统凭据库；完整回复自动进入聊天历史。未完成回复明确标为中断，默认不进入后续上下文，可显式使用或重试。
4. 群聊默认 @指定，也支持轮流、全员和情境（额外一次选择调用，最多 3 人）。每成员每批最多回复一次、总计最多 8 条，逐角色串行；可跳过尚未开始的成员，队列完成即停。人设私有字段只注入本角色，选择请求只使用公开资料和共同可见历史。
5. 在「成员、人设与声音」管理成员、禁言、顺序和稳定音色。角色库修改不追溯更新会话；主动应用角色/用户身份新版先比较修订并停止旧轮。新成员默认只见加入后消息，记忆也不能绕过这个边界。
6. 选择 TTS 或成员预选声音，并显式开启自动朗读。回复封句后即准备完整短音频，不等整条文字结束；播放使用共用音频资产/缓存及唯一前台焦点。最多 3 段待播，全服务共用一个语音锁。积压只继续保存文字；暂停/继续、语速、音量、单条或单句重播均可操作；明确标记的动作/环境段默认跳过，也可显式开启朗读。
7. 「停止语音」立即清空前台播放并停止本轮后续自动合成，文字可继续；「停止本轮」还取消 LLM 和剩余成员。新消息、路径变更、依赖修改与会话切换隔离旧 epoch，旧音频不能恢复当前播放。重开会话/重启不自动续聊或发声。
8. 「上下文预览」显示逐角色来源、裁剪和保守 token 估算，也可查看本轮实际请求快照。「会话记忆」可手动保存带消息来源、接收者、事实/推测和锁定标记的记忆；当前没有自动语义记忆提取。消息编辑、变体选择与「历史路径」保留旧路径，重复请求幂等，冲突保留输入。
9. 「从作品复制人物」选择作品/分支、可见章节/章首或章末、简介/背景字段，先预览再复制。作者资料需明确选入，只能默认映射到本角色背景，不能默认为群成员公开简介。复制保存来源，不回写作品或自动检索小说。
10. 「导出聊天」仅导出当前所选消息；完整 `.narravo` 备份包含全部角色修订、会话路径、变体、记忆、声音计划和轮次状态，可选已有音频。服务配置、密钥与外部请求授权不随备份恢复。

语气建议目前是使用可见对话、人设风格和场景的本地规则。已核对 MiniMax 官方资料，在**具体 MiniMax 2.6 hd/turbo 配置**的高级设置中可显式启用 happy/sad/angry 和速度参数；人工覆盖优先，其他语气/模型/服务明确回退普通语气或默认速度，保持音色。该开关不代表账号实测通过。无 TTS、失败或费用/队列不足时保留文字；手动重试未知远端结果可能重复计费。

聊天、人设、开场白和回复不会写入小说正文、作品事实或默认听书队列。麦克风、ASR、全双工通话、声音克隆与外部角色卡完整兼容不在本轮范围。实现和验收边界见 [ADR-0005](docs/adr/0005-roleplay-conversations.md) 与 [角色扮演验收](docs/evaluations/0004-roleplay.md)。

## 启动开发版

需要 Node.js 22.12+（本机验证 24.19）、pnpm 10.33、uv、Rust 工具链及目标系统构建工具。macOS 需要 Xcode Command Line Tools。首次需联网下载依赖。

```sh
pnpm install --frozen-lockfile
pnpm engine:setup
pnpm dev
```

`engine:setup` 通过 uv 创建 Python 3.12 环境，使用已提交的 uv.lock。`pnpm dev` 首次会构建 sidecar，然后启动 Vite 与 Tauri；已存在 sidecar 时，开发模式直接运行 Python 虚拟环境中的源码。Rust 工具链需包含 `rustfmt` 和 `clippy`。

本次开发的工具链安装在忽略的 `.build-tools/` 下，启动脚本会自动识别；没有修改全局工具链与 shell 配置。普通开发者也可直接使用系统 Rust。依赖缓存位于项目内部，首次运行 `engine:setup` 可能下载 Python。

```sh
pnpm dev:web       # 只看浏览器界面；普通浏览器没有本地引擎，不提供作品持久化
pnpm build         # 只构建网页，不代表桌面安装包
pnpm desktop:build # 先打包 Python，再构建当前系统的应用包
```

macOS 当前产物在 `apps/desktop/src-tauri/target/release/bundle/macos/Narravo.app`。它包含引擎，不要求用户额外安装 Python。该应用仅在本机测试，未签名公证，未验证在无开发工具的干净机器上的安装和 Gatekeeper 行为；配置的最低 macOS 版本不是已验证的兼容性承诺。

## 数据与隐私

- 开发模式使用项目根目录 `.dev-data/`，不接触正式书库。打包应用默认使用系统应用数据目录，界面不接收或展示任意文件路径。
- 原生文件选择框控制导入和导出。TXT 上限 10 MiB；EPUB/PDF 文件上限 100 MiB、提取正文 8 MiB；PDF 最多 2,000 页且整份处理最长 180 秒。备份压缩文件/解压总量均上限 1 GiB。具体限制见 [ADR-0004](docs/adr/0004-document-import-portable-backup.md)。
- 可通过启动进程的 `NARRAVO_DATA_DIR` 环境变量指定隔离数据目录，供本机原生测试使用。不要把真实书库用于故障注入。
- SQLite 使用 WAL、foreign keys 和短事务。正文/规划修订和快照只追加；分支头可前进。导入原始字节单独保存，导入清单保留 TXT 章节级字节范围、EPUB 资源 body、PDF 页码来源，尚未实现逐段精细定位。
- 目前每章有一个稳定正文锚点；逐段锚点和光标任意插入 UI 仍待完善。写作助手当前固定在章节末尾生成。
- 本地数据未加密。不要把 `.dev-data/`、实际小说、密钥、音频缓存或模型权重加入仓库。
- 模型设置中保存配置不会请求云端；开启外部请求后，仅点击测试、生成或确认合成才发起请求。短文测试固定问候语，语音测试固定一句话，均可能计费。小说正文与所选作者规划只在明确生成时发送；普通朗读只发送已保存正文，不发送规划或候选。
- 关闭外部服务会取消活动网络任务。已经发出的请求可能继续计费；401、限流、超时等均不自动重发；重启不自动重放远端请求。
- 真实生成按自定义服务配置运行。系统代理环境变量不会自动继承到 HTTP 客户端；需要专门代理的网络需配置可访问的服务地址。
- 小说整章音频仍为固定旁白模式；聊天独立绑定成员声音，表达能力范围见上文。不支持 SSML、声音克隆或逐字时间戳；只展示片段文本。单次合成上限一万 Unicode 字符，默认分段最多 280 字符，语音请求串行以避免并发缓存重复计费。

## 验证

```sh
pnpm lint
pnpm test
pnpm engine:test
pnpm engine:lint
pnpm engine:bundle   # 独立执行 Rust 检查前需要 sidecar 资源
pnpm desktop:check
pnpm test:e2e
pnpm desktop:build
```

`test:e2e` 使用真实 Python 引擎、隔离临时数据库和确定性演示 provider，通过测试专用浏览器桥接和 HTTP 响应替身运行，测试独占端口 1421，不创建生产 HTTP 业务服务；该桥接仅在测试环境变量启用时生效，正式包不包含启用入口。首次需 `pnpm exec playwright install chromium`，或通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定已安装的测试浏览器。浏览器测试不替代 Tauri 原生权限与生命周期检查。

协议以 `services/engine/src/narravo_engine/contracts.py` 为源，执行 `pnpm contracts:generate` 同时生成 JSON Schema、TypeScript 类型、方法映射和静态校验器；`contracts:check` 防止漂移。Rust、前端和引擎共用生成结果，不手工修改生成文件。

测试与边界见 [角色扮演验收](docs/evaluations/0004-roleplay.md)、[导入与备份恢复验收](docs/evaluations/0003-import-backup.md)、[首轮验收记录](docs/evaluations/0001-local-writing.md)、[模型接入验收](docs/evaluations/0002-providers.md)。架构决策见 [ADR-0002](docs/adr/0002-local-writing-foundation.md)、[ADR-0003](docs/adr/0003-provider-integration.md)。

## 导入与完整备份恢复

在作品库点击「导入你的小说」，选择 TXT、EPUB 或 PDF，检查章/页顺序和正文样本，再确认创建作品。EPUB 仅支持无 DRM 的流式文本；脚本和外部资源不会执行或下载。PDF 的密码不保存，扫描页、坏页或超时页显示遗漏；必须勾选接受不完整导入才能继续。页眉页脚去重可选开启；不承诺复杂排版恢复。

作品库的「备份与恢复」可创建整个当前书库的完整备份，按需包含已有音频，准备完成后选择保存位置。备份包含作者秘密且未加密，请妥善保存。恢复先选择 `.narravo` 文件并校验，再点击「恢复为独立书库并切换」；原书库保留，界面可往返切换。恢复前先停止活动生成/语音任务。恢复不会自动重发远端任务，也不恢复模型密钥或网络授权。已有进度字段会随数据库保存，但尚未实现的书签/阅读进度不在当前能力范围。

## 配置真实模型

1. 重启桌面开发版（`pnpm dev`）或打开新构建的应用，进入左侧「设置」。
2. 分别进入「文本模型（LLM）」与「语音模型（TTS）」页签：各自选择服务预设、填写模型 ID 和 API Key；TTS 还需填写账号支持的音色。两页的已保存列表、编辑草稿、密钥输入和保存操作独立，切换页签保留未保存内容。云服务保持 HTTPS，本地服务需在高级参数中明确允许本地地址。
3. 点击对应的「保存 LLM 配置」或「保存 TTS 配置」，只保存当前类别。已有配置按类型自动归类。开启「允许外部模型请求」（两类服务共用的总开关）。密钥进入系统凭据库，应用不会读回展示。修改服务地址后需重新填写密钥；可移除此配置的已保存密钥。
4. 按需点击当前页的「测试 LLM（可能计费）」或「测试 TTS（可能计费）」：只使用固定短样本。高级开关由具体模型能力决定，默认不发送温度和可选 stream_options。
5. 打开作品，选定文本模型与可选参考设定。有前文时无需填写意图，直接点击「继续写」；生成前会先保存最新正文，从当前章节末尾续写，也可在空的新章节承接前章。意图框只用来补充剧情方向；当前位置没有前文时填写一句开篇想法。生成仍进入候选区，接纳后才写入正文。保存模型配置会选中该配置；也可以随时切回固定样文的本地演示。若提示外部请求已关闭，点击旁边的设置入口开启「允许外部模型请求」；保存配置不会自动开启总开关。
6. 选择 TTS 配置，点击「准备本章语音」，核对发送地址、音色、字符范围与费用提示后确认。合成完成后播放；重复准备会复用匹配的缓存。

具体预设、协议范围和官方文档来源见 [模型接入验收](docs/evaluations/0002-providers.md)。模型 ID 与区域不保证长期固定，所有账号实测结果均以实际测试为准。
