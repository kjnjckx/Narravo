# ADR-0002：先交付可持久化的本地写作与可验证的 stdio 基础

- 日期：2026-10-16
- 状态：首轮已实现；真实模型与发行验证待完成
- 对应：NEW / PLN / WRT / CTX / VER / DAT；重点 AC-20，部分覆盖 AC-09 / 18 / 24–28 / 30–31

## 问题

开工时仓库只有规划文档，没有代码、锁文件或 Rust 环境，也没有经用户确认的模型账号与区域。需要立即形成实际可用的纵向闭环，同时不能以固定样文或网页测试冒充真实模型、听书和原生发行验收。

## 决策

沿用 Tauri 2 / React / TypeScript / Python 3.12 / SQLAlchemy / Alembic，不增加业务 HTTP 服务或 Agent 框架。Rust 只管理进程、原生文件选择和受控桥接，Python 是业务数据库唯一写入者。

第一轮实现无模型的新建、按章手写、不可变修订、章节结构、规划、分支、历史恢复和正文导出，先形成 AC-20 的可测试基础。新建事务原子创建作品、空规划、默认分支、章节和锚点。快照只保存章节元数据和修订引用；读取编辑正文按章请求。修订内容保持来源，规划不与正文混存。

为验证候选与任务流程，增加明确标注的 deterministic demo provider。它不访问网络、不产生费用，只生成固定样文。候选保存上下文快照和正文/规划依赖；接纳事务检查快照、锚点、候选修订、选择范围与幂等键。恢复版本产生新快照，不覆盖旧记录。

协议采用带 schema_version 的单行 JSON-RPC 2.0；引擎单写 stdout，诊断不返回任意异常文本。Pydantic 方法注册表生成 JSON Schema、TypeScript 类型、方法映射和静态响应校验器；生产 CSP 禁止动态代码生成，不在界面运行时编译 schema。前端验证响应和版本；Rust 只允许注册方法，限制帧大小，处理超时、进程退出和待响应请求。前端当前使用持久化 task.get 获取候选进度，不依赖通知必达；引擎仍发 task_id / seq 事件。仅本地演示任务允许按已发送字符检查点继续，未来远端 adapter 必须单独处理 UNKNOWN_OUTCOME。

PyInstaller 将引擎与迁移资源打成当前目标的 sidecar，再由 Tauri externalBin 打包。应用关闭先保存，随后关闭 stdin；引擎收到 EOF 后关闭数据库退出，Rust 限时等待后回收进程。

## 替代方案

- 仅做静态 UI：无法证明保存、接纳和冲突规则，因此未采用。
- 为浏览器预览增加 HTTP 业务服务器：违背首版桌面进程边界，因此未采用。浏览器流程测试使用测试端直接转发 stdio，生产代码不启用此入口。
- 立刻选择任意云模型并请求：没有账号与区域实测依据，也没有费用授权，故当前只做演示，不声称真实 AI 已完成。
- 等全部真实模型验证后再写本地功能：会阻塞与云服务无关的 AC-20；因此有意识地前置这部分 M1/M4 的基础，M0 的真实模型与音频关卡仍保留。

## 代价与限制

初版存储使用章节级不可变正文与 JSON manifest，规划以独立修订列表保存，单章单锚点。尚未实现逐段 TextRevision、FTS、结构化规划候选和音频数据模型；后续必须通过新的 Alembic 迁移扩展，不能重建生产数据库。当前 schema 没有凭据或付费调用。

上下文读者策略保守地以披露章节之后为可见边界；删除披露章节会保持隐藏，尚未提供专门的失效锚点修复 UI。作者规划可明确选用作者秘密，因此不承诺作者秘密绝不发送模型。

前端暂用 task.get 轮询以验证持久化终态。大规模任务、分段索引与复杂背景调度需在后续按测量改进。全文导出目前通过 RPC 文本返回，后续长篇大文件改为资产引用。

## 验证与迁移

已提供隔离临时数据库的行为测试、stdio 子进程测试、前端 Unicode/合同测试和真实引擎的浏览器流程测试。打包引擎在不可用系统 Python 路径环境下独立启动验证通过。原生、干净机器和真实模型验证状态分别记录于评测文档。

首轮使用 Alembic 0001 建库。Storage 在有版本的库需要升级前使用 SQLite backup API 保存一致性副本，迁移由事务执行。后续 schema 升级必须新增迁移并测试失败回滚，当前测试仅覆盖首次建库、重新打开和 WAL 一致性快照，不把它当作完整迁移验收。
