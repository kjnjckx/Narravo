# ADR-0003：多协议模型入口、系统凭据库与可恢复网络任务

- 日期：2026-10-16
- 状态：实现与替身测试通过；真实账号验收待用户配置
- 对应：PRO / WRT / TTS / DAT，AC-05 / 06 / 07 / 09 / 12 / 18 / 19 / 20 / 21 / 25 / 31 的相关子集

## 问题

现有生成仅为固定演示文本。用户明确要求接入 DeepSeek、OpenAI、GLM、Claude 等 LLM，以及 MiniMax、OpenAI 等 TTS，并尽量支持更多服务。不同厂商的协议、鉴权和音频响应不同，不能把所有服务都声明为完全兼容。

需要保持密钥不进入前端读回/数据库/备份，网络不阻塞本地保存，未知远端结果不被重发，语音只朗读已保存正文，编辑后不混入旧修订音频。

## 决策

1. 以窄 HTTP adapter 实现 Chat Completions、Responses、Claude Messages 三种文本协议；语音使用 OpenAI Speech、MiniMax HTTP hex、ElevenLabs 三种协议。厂商预设只提供地址/协议/少量有文档依据的示例，模型 ID、区域、音色均可修改。所有账号能力仍需实际测试。保留演示模式。
2. 配置保存在 Python SQLite，独立于作品/规划。Rust 使用 keyring 3.6.3 的原生 macOS Keychain / Windows credential feature；仅测试 macOS。密钥引用由配置 ID 与确切基础地址组成。Rust 的专用命令写入/移除凭据，通用 RPC 不允许注入内部字段或直接保存凭据元数据。前端输入仅暂存，保存后清空，任何接口均不读回密钥。
3. 请求时 Rust 读取相应凭据，沿私有 stdio 字段传入 Python，域入口先移除这些字段，再验证公开 schema。Python 只把密钥保留在当前后台任务内存中，不写任务、生成、错误或 provider 元数据。请求同时绑定当时地址，地址变化拒绝发送，避免凭据被送往另一个目标。
4. stdio 主循环运行 asyncio；HTTP 网络任务 await，SQLite 事务保持短小，期间本地保存与取消仍可处理。记录已收到文本、序号、用量和实际可获得的模型标签。取消保留部分候选；进程非正常中断后的远端 running 任务标 UNKNOWN_OUTCOME，不自动重发。网络异常/认证/限流均无自动重试。
5. 外部请求默认关闭，用户可明确启用/关闭。测试请求只发送固定问候语，按钮明确可能计费。实际生成发送所选上下文；朗读只读取目标章的已保存正文，不读取规划和候选。单次输出 token、上下文、合成字符数和并发有限制；没有金额账本时费用显示未知。
6. 语音默认每片段最多 280 Unicode code points，保留完整源覆盖和稳定范围，单次最多一万字符。固定旁白声音，不发送未实现的情绪/SSML参数。语音任务串行，共享缓存校验与提交锁，避免相同输入的并发重复请求；文本任务和本地 RPC 不受此串行锁影响。
7. 音频先有界下载，再校验 WAV/MP3、落临时文件、fsync、原子改名、写资产元数据，之后才进入任务的可播放 segments。缓存键包括正文修订、范围、实际文本、服务地址/协议/模型/区域/音色、格式和 adapter/plan 版本，不包含无关作者规划。通过唯一索引防止重复元数据。
8. 前端通过资产 ID 取得已校验的单段音频，不接触任意文件路径或远端音频 URL。当前使用有界 base64 帧转 Blob 播放，CSP 只增加 media-src blob，不放宽脚本策略。播放器绑定分支、章节与正文修订，草稿编辑/切章立即暂停旧音频并取消未完成的旧合成；无逐字时间戳，仅展示片段。

## 替代方案

- 为每家服务引入完整 SDK：增加打包体积与类型泄漏，最小文本/语音协议用 httpx 足够。
- 所有厂商都使用同一 payload：Claude 鉴权/事件及 MiniMax hex 与二进制语音存在实质差异，不能共用一套假定。
- 在 React 直接请求云服务：会暴露密钥、打破生命周期和数据库边界，未采用。
- 超时或重启后重放请求：不能保证只计费一次，未采用。
- 首次即做多角色和真流式 PCM：先验证完整片段缓存播放，复杂情境分析保留后续。

## 迁移与验证

新增 Alembic 0002（配置、外部请求开关、音频资产）及 0003（唯一缓存索引）。Storage 从迁移脚本动态取得 head，升级前使用 SQLite backup API 建立快照；显式 BEGIN IMMEDIATE 保证 sqlite3 legacy transaction 模式下 DDL 也可回滚。测试验证 0001 数据保留、升级前备份和注入失败后表结构/版本回滚。

每种协议使用确定性 HTTP 替身验证请求路径、鉴权、事件、文本与音频。普通测试不调用真实服务。系统凭据库用独立假密钥执行写入/读取/移除；与真实账号无关。完整结果与官方资料见 [接入验收记录](../evaluations/0002-providers.md)。

## 范围与代价

当前为基础文本生成与固定旁白。没有远端价格数据库/金额预算预留、完整 capabilities 探测、动态模型/音色目录、代理设置、结构化规划候选、角色/情绪分析、逐字对齐、声音克隆、音频导出或连续跨章自动编排。模型 ID 及参数限制由用户实际账号确认。代码可配置、替身测试通过与真实服务验收分别报告。

服务响应中的 JSON 与文本始终作为数据；不执行工具调用。MiniMax 使用 hex 音频，其他 TTS 使用响应体，不下载云响应给出的任意 URL。HTTP 重定向拒绝，私有地址需用户明确允许，不继承环境代理。
