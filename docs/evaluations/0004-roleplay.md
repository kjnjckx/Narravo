## 可操作入口

左侧「角色」→「新建角色 / 用户身份」→「新建单聊 / 群聊」。人设保存、复制、归档、PNG 本地头像、用户身份/场景、会话创建、历史浏览、无模型消息保存和导出不发起网络请求。

选择设置中已有 LLM，发送或 Ctrl/⌘ + Enter 生成。复用现有 LLM adapter、服务选择、外部请求总开关和 Rust 凭据桥接；完整回复自动进入聊天历史，不进入小说正文。中断文本另行显示，须显式使用。群聊默认 @指定，支持轮流、全员和情境选择，有可见队列、跳过和累计用量。

成员配置可比较并应用角色/用户身份新版，固定人设修订、声音、加入位置和成员 ID。旧会话、其他会话及角色库不互相回写。上下文预览显示逐角色输入、来源、裁剪与估算；本轮实际请求快照也可查看。记忆目前由用户手动建立，必须选取当前路径的可见来源，区分事实/推测和锁定，不包含自动语义提取或跨会话记忆。

开启自动朗读后，已封句片段可在文字结束前合成和播放。可选全部或首位发言者、固定声音、语气/合成速度覆盖、播放速度、音量、暂停/继续、单条或单句重播。停止语音与停止本轮分别控制，前台先停止播放，再持久化状态。语音无配置、失败或积压时保留文字。

作品复制入口选择作品/分支、章首或章末、公开简介/本角色背景字段，预览后确认。隐藏作者资料需单独选入，不默认复制为公开简介；复制保存来源，不自动同步作品。聊天普通导出只有当前路径消息；完整书库备份包含全部修订、路径、变体、记忆、声音和轮次，可选已有音频。

## 原生证据

使用单独 bundle identifier 的重签验收副本、全新隔离书库和 `tests/native/roleplay_fixture.py`。替身只监听 loopback，无密钥，返回固定 SSE 及有界 WAV 测试音，不能视为真实语音质量样本。

- 原生可访问性树显示独立角色入口、3 个人物、单聊与群聊会话、稳定成员编号、@、队列、语音与停止控件。
- 原生 Ctrl/⌘ + Enter 发送 ASCII 测试消息后，出现「流式回复中」和「正在朗读首句」的同时状态；首句缓存命中亦能正常播放。
- 生成中停止本轮，出现「中断回复 · 未进入后续上下文」；停止语音后文字最终完整保存，播放器无当前语音。
- 原生三角色全员轮次持久化为 completed、3 位 completed_members、3 条角色回复。没有递归下一轮。
- 正常退出后测试应用与其 sidecar 进程为 0，数据库 integrity_check=ok，schema=0004；测试共 6 轮，其中 1 轮取消，其余完成，所有语音均停止。原生凭据隔离假密钥回环另行通过。
- 关闭 loopback 替身后重新启动验收副本，三条群聊回复仍可读取；自动朗读为关闭、播放器禁用，轮次请求数保持 3，没有自动续聊或发声。再次正常退出。
- CUA 首次连接曾非常缓慢，该耗时未计入产品延迟。上述检查不测量真实首声、静音 P95、长时音频间隙或听感。

## 复现

```sh
pnpm engine:test
pnpm engine:lint
pnpm lint
pnpm test
pnpm test:e2e
pnpm desktop:check
pnpm desktop:build
```

需要时使用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指向已安装的测试浏览器。原生替身需在全新空目录运行 `tests/native/roleplay_fixture.py --data-dir <测试目录> --port 1438`，用 `NARRAVO_DATA_DIR` 启动单独验收副本；不可指向用户书库。测试角色和 loopback 配置由该脚本初始化，应用中选择「原生本地替身 llm」，角色已预选测试声音。结束后关闭副本和替身服务。该脚本不打入正式应用。

真实验收须另获调用授权，使用最短虚构样本记录账号模型/区域/声音、账单用量、人设遵从、安慰/争执/低声表达、首 token/封句/首声与停止时序，并在 WKWebView 人工听验。当前没有真实凭据或付费调用授权，因此这些项目明确未执行；不影响本地功能或可配置接入代码交付。

## 保留限制

当前只有文本到分句完整文件的语音路径；不含 ASR、麦克风、全双工、克隆或外部角色卡。语气规则是保守关键词建议，复杂上下文和文学动作尚未做语义识别；未结构化动作按可见文字普通朗读，不凭正则删掉对白；用户明确标记的动作/环境段可默认跳过，或显式开启朗读。没有自动摘要/语义记忆提取、千轮长聊性能保证或跨会话记忆。版本列表和当前路径当前以会话粒度读取，超长聊天分页/性能需后续实测。金额估算不保证远端恰好计费一次，也不保证用户填写的单价正确。

MiniMax 参数于 2026-10-17 核对 [官方 HTTP 文档](https://platform.minimax.cn/docs/api-reference/speech-t2a-http)、[官方 TTS Guide](https://github.com/MiniMax-AI/skills/blob/main/skills/frontend-dev/references/minimax-tts-guide.md) 与[官方参数实现](https://github.com/MiniMax-AI/skills/blob/main/skills/frontend-dev/scripts/minimax_tts.py)。仅支持明确启用的 2.6 manual emotion/速度子集，未核验账号权限，不擅自改 endpoint、region 或 voice。
