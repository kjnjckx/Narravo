## 行为与失败证据

### EPUB

- EPUB 3 nav、EPUB 2 NCX 标题；文件名顺序与 spine 相反时，正文按 spine 导入。
- 中文、emoji 和相对资源定位保留；脚本、样式和嵌入内容不进入正文。只返回纯文本，不渲染原始 HTML。
- 目录穿越、绝对路径、Windows 路径、反斜杠、符号链接、压缩炸弹、外部实体及缺失 spine 资源明确失败。
- 预览不创建作品；确认后保留原始字节副本，复用共用 Book/编辑器。

### PDF

- 真实最小文本 PDF 可预览；无文本页返回 OCR_REQUIRED；混合文档明确记录遗漏页码。
- 未明确接受不完整结果时，UI 禁用确认，后端返回 INCOMPLETE_IMPORT；接受后仅导入有效页。
- 加密 PDF 的缺密码/错密码有明确错误，正确密码可提取；任务记录不保存密码。
- 损坏文件、注入坏页和可选的重复页眉/页脚规范化有测试。实际坏页证据是确定性的解析失败注入，尚无广泛真实出版 PDF 语料结论。
- 取消测试实际终止并回收解析子进程，不创建作品；重启后未完成文件任务被标记中断。

### 完整备份与恢复

- 原创空作品、空章、导入原文件、全部快照、父/子分支正文、作者秘密、候选和部分接纳决策均能恢复。
- 快照显式关闭连接并采用独立 DELETE journal；归档不依赖 live WAL。测试修改备份数据库时也显式关闭连接，避免把未 checkpoint 的 WAL 错当主文件更改。
- 可选音频分别验证：包含时完整字节及 audio.read 可用，不包含时索引/播放计划移除；不自动合成或请求云端。
- providers/preferences 与历史服务地址/凭据存在标志不进入可移植备份；恢复默认关闭网络。历史模型来源/用量仍保留。活动远端任务冻结为 UNKNOWN_OUTCOME，不自动重放。
- 版本、文件集合、大小、校验和、数据库 schema、完整性、外键及正文/候选/决策引用均先校验再切换；损坏包不改变当前书库。
- 注入备份写入磁盘满和选择指针写入失败，验证无半份正式备份、当前库仍可读写；恢复前库保持完整，重启选择正确书库，可在 UI 往返切换。
- 高压缩比但在总量上限内的合法源文件可备份恢复，不被 EPUB 专用压缩比保护误拒绝。

## 验收边界

| 编号 | 当前证据 | 保留限制 |
| --- | --- | --- |
| AC-02 | EPUB 2/3 标题导航、spine 顺序、相对资源、纯文本清理；原生 EPUB 导入 | 无 DRM 流式书；封面仅保存资源定位，不显示；媒体/特殊排版不保留 |
| AC-03 | 文本/无文本/混合/加密/损坏 PDF、遗漏确认、分页资源隔离；打包 worker 和浏览器流程 | 不实施 OCR；坏页由确定性注入覆盖；多栏/竖排与广泛字体兼容、低质量 OCR 识别能力未全面评测 |
| AC-15 | 空白目录恢复、完整资产与数据库、切换/重启/回切；原生保存与恢复 | 仅备份格式 v1 / schema 0003，不做合并；尚未实现书签与阅读进度，没有这些数据的验收结论 |
| AC-16 | ZIP/XML 安全边界、无脚本/远程资源自动加载 | 未声称第三方解析器无所有安全缺陷，仍需后续依赖维护和模糊测试 |
| AC-28 | 正文导出仍排除作者规划；完整备份保留秘密、分支和接纳决策；不含密钥 | 备份未加密，用户需妥善保管 |

本轮未执行：正式签名/公证、干净 macOS 或 Windows 安装、VoiceOver 全量评估、千页 PDF 性能、各类 EPUB 出版商兼容语料测试、系统崩溃/断电级持久性实验。运行时有超时与资源限制，不把保护值当作性能承诺。资源限制在不支持 resource 模块的平台以可终止进程和墙钟上限为主；Windows 未验收。

数据库业务 schema 没有变化，仍为 Alembic 0003；新书库选择指针是本地存储布局扩展。本轮没有迁移、清理或覆盖用户正式书库，也没有将测试二进制文档/书库/音频加入源码目录。
