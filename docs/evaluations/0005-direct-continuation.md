# 默认续写与外部请求入口修正

- 日期：2026-10-17。
- 对应需求：PRD 5.3、9.2「继续写 / 按指令续写」、9.6 空白开篇；AC-08 上下文隔离、AC-19 模型配置入口、AC-21 开篇、AC-23 已接纳正文续写。
- 问题：界面和两个生成入口都强制要求非空意图，遗漏需求中已经声明的「使用默认继续」。截图同时显示外部请求总开关关闭，保存 DeepSeek 配置不代表已授权网络请求。

## 本次行为

有可用前文时，意图可留空，点击「继续写」先保存最新编辑内容，再用默认指令自然承接原有视角、文风和未结束的句子。空新章可以使用当前分支之前的正文。引擎根据策略过滤后的实际上下文判断能否续写，不以全书字数或未接纳候选放行；插入点后方的文字不能绕过无前文检查。没有前文也没有意图时继续返回 EMPTY_INTENT，不创建生成任务。

显式填写的意图仍优先使用。演示与配置服务共用意图解析；真实请求快照保存最终提示词，仍保留候选接纳、版本冲突和费用提示。当前写作位置仍为章节末尾，本次未实现任意光标插入。

外部请求关闭时禁用新生成，显示具体原因和直达文本模型设置的按钮。打开设置不自动授权或发送请求。没有修改用户总开关、密钥、数据库或服务地址。
